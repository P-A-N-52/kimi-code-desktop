## Kimi Code Desktop v0.1.12

相对 **v0.1.11** 的热修复（原计划记为 0.1.11.1；Cargo/semver 仅支持三段版本号，故发布为 **0.1.12**）。

### 严重修复：工具审批被静默拒绝

- Kimi Code CLI **0.29.1** 只接受 ACP `optionId`：`approve_once` / `approve_always` / `reject`
- 桌面端此前发送 Zed 风格的 `allow-once` / `allow-always` / `reject-once`，CLI 全部落入 default → **rejected**
- 表现：UI 已是 auto / 已点「允许」，AgentSwarm、Bash、ExitPlanMode 仍在数十毫秒内显示「user rejected the approval request」

### 权限 / Plan 模式抖动

- 前端：`permission` / `plan` / `swarm` 模式 flush 改为单飞队列，避免并发清空 pending
- 发送 prompt 前先 await 模式生效；`StatusUpdate` / 历史回放不再覆盖本地未落地的模式意图
- Rust：Plan/权限 `session/set_mode` 加互斥锁；设置权限时先提交本地 permission，避免 Plan recovery 用旧的 Manual 写出 `default`

### Swarm UI

- `AgentSwarm` 在 `output-denied` 时显示「已拒绝 / 未执行」与错误文案，不再误显示「等待子代理启动…」
