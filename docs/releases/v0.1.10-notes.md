## Kimi Code Desktop v0.1.10

相对 **v0.1.9** 的更新说明。

### 新会话 / 工作目录
- 新建会话改为完整「新会话」页，可先选工作目录再发首条消息
- 工作目录选择器：最近目录 + 自定义路径；新会话支持部分 slash 命令与模型切换
- 新会话页增加状态条（连接 / 模型 / 权限）
- 已有会话工作目录改为只读，避免误改

### 窗口与侧栏
- 无边框窗口；顶栏最小化 / 最大化·还原 / 关闭；可拖拽移动
- 会话搜索；按时间 / 按项目分组；进行中 / 已归档与批量归档恢复

### Composer
- `@` 引用工作区文件；拖拽上传文件
- 「上下文」改为「文件」；占位与 slash 菜单交互优化
- CLI 断开时禁用发送；修复快速连点重复发送

### 字体与视觉
- 主字体改为 HarmonyOS Sans SC
- 主题切换动画更稳妥；窄窗口侧栏 overlay

### CLI 对等
- `/usage`、`/status` 输出对齐 CLI TUI
- ACP 命令更新合并更稳，减少指令菜单缺项

### Agent / Swarm
- Agent、Swarm 专用工具卡片（对齐 Web，可展开步骤）
- 相关解析与 UI 原语、测试补齐

### 设置与运行时
- 正确持久化 `[thinking].enabled`
- 权限 / 运行时模式与状态栏展示修复

### 对话稳定性
- 断线错误横幅与「重新连接」
- 打开会话加载更快；Agent 监控状态更准确
- Markdown 表格不再多余下载控件；`Ctrl/Cmd+N` 新建会话

完整草稿见仓库 `docs/releases/CHANGELOG-draft.md`。
