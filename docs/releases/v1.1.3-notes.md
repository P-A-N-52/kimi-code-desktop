# Kimi Code Desktop v1.1.3

相对 **v1.1.2** 的长会话流式性能、桌面更新提示与配置编辑体验更新。

## 长会话与流式性能

- 延长 ACP 长时间 `session/prompt` 的默认超时，并缩短会话 worker 的锁定范围；长时间、多工具任务期间仍可处理反向请求和取消操作。
- 高频文本 wire 输出按时间窗口和大小聚合，终态路径会先刷新待发送文本，降低流式更新开销并避免长文本末尾内容丢失。
- 历史回放改为分批提交，前端流式内容按帧节流；加载更早消息时保持滚动位置，长会话的消息、工具、子代理、终端和差异内容展示更加平滑。
- 修复长会话分页提示在中英文界面下的文案转换问题，并增加长会话流式、回放、文本聚合和消息展示的回归测试与基准 fixture。

## 桌面更新体验

- Tauri 桌面端启动后会非阻塞检查 GitHub 最新 release；发现新版本时在设置入口显示“可更新”标记，更新检查失败不会阻塞应用启动。
- 增加桌面版本比较与更新检查测试，覆盖带 `v` 前缀、旧版本、相同版本和无效版本号等情况。

## Provider 与模型配置

- 设置页增加结构化 Provider / 模型配置编辑器，支持新增、重命名和删除 Provider 与模型，以及编辑连接地址、API key、环境变量、自定义 Headers、上游模型、显示名称、上下文长度、Capabilities、思考档位和默认模型。
- 配置以本地草稿形式编辑，保存时写回 `config.toml`；TOML 解析、变更、格式兼容性校验和删除默认模型后的自动回退均由独立模块处理，并保留嵌套设置及无关配置内容。
- 保护 Kimi Code 内置 Provider 的名称、类型和删除操作；结构化配置解析、编辑器加载保存、删除确认、保存失败和不兼容 TOML 等场景均补齐测试。

## 应用内确认对话框

- 增加统一的应用内确认对话框，以 `ConfirmDialogProvider` / `useConfirm` 替代 `window.confirm`；修复 Tauri WKWebView / WebView2 不显示原生确认框、导致确认操作静默失败的问题。
- Provider、模型删除和配置切换时的未保存更改拦截改用桌面端可用的确认对话框；取消操作会保留当前草稿，并补齐确认、取消和删除流程测试。

## 验证

- 前端测试覆盖长会话 runtime/replay、分页文案、桌面更新版本比较、结构化 Provider / 模型 TOML 与编辑器、应用内确认对话框。
- Rust 测试覆盖 ACP 文本聚合、批量刷新和终态刷新路径；新增长会话 fixture 与 benchmark 脚本用于回归验证。
