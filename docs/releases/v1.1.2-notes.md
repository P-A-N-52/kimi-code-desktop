# Kimi Code Desktop v1.1.2

相对 **v1.1.1** 的会话稳定性与长会话性能更新。

## 关键修复

- 修复同一会话的并发连接和重复 wire listener 导致 Markdown 文本、工具卡片及状态事件重复渲染的问题（#12）。
- 修复 ACP worker 已关闭或被替换后界面仍停留在“模型响应中”的问题；失败会进入明确终态，并为可恢复错误提供带进度反馈的“重新连接”操作。
- 修复会话切换或选项刷新时 runtime 已创建但未正确启动，以及 prompt 失败后被错误保留并反复重发的问题。

## 长会话与 Todo（#13）

- TodoList 只保留最新完整快照，并兼容 `TodoList`、`Todo List` 与 `todo_list` 等 ACP 工具名形态。
- 历史消息首屏限制为最近 120 条，按 100 条加载更早消息；加载时保持当前滚动位置。
- 消息组件增加稳定回调、memo 与离屏内容跳过布局，降低长会话重渲染和滚动开销。
- permission mode 在模型响应期间仍可从 yolo、manual、auto 间热切换；Plan、Swarm 与 Goal 的忙碌态限制保持不变。

## 会话状态

- 会话侧栏增加 runtime 状态指示：响应中呼吸、已连接静态、空闲隐藏、错误红点。
- 连接错误只在确实可重连时显示重连按钮，重复点击会被抑制，并显示“正在重连…”状态。

- macOS Apple Silicon debug bundle 真实验收：#12 Markdown 单次渲染；#13 Todo 合并、运行中权限热切换及 3695 条 wire 记录长会话分页通过
