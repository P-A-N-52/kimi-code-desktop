# Kimi Code Desktop v1.1.1

相对 **v1.1.0** 的稳定性更新。

## 关键修复

- 修复切回仍在执行任务、但前端 wire lease 已断开的会话后时间线冻结的问题；桌面端会重新连接并补齐缺失事件，避免下一条消息误入失败队列。
- 修复打开模型选择器时会话配置尚未加载的问题；连接会按需建立，模型与 Thinking 状态不再停留在空白或旧值。
- 修复全局模型配置更新触发启动就绪遮罩、重复检查或多余状态跳转的问题；非阻塞配置更新保持桌面可用。
- 修复历史回放中的文件改动自动打开 Workspace 面板，以及切换会话时历史 Goal 完成记录误晋升下一条 Goal 的问题。

## 会话与配置稳定性

- Tauri Desktop 默认使用多活跃会话编排器，每个已访问会话保留独立 runtime；Web / 非 Tauri 环境继续使用单 stream。
- Secondary model 实验开关、模型 alias 与默认思考档位可以从 Settings 原子写入 `config.toml`，并遵循 Kimi Code 0.31.1 的实验开关优先级。
- 保存全局配置或原始 `config.toml` 后会使共享 ACP session client 失效，确保后续会话读取最新配置；空闲 wire worker 会重启并进行 replay gap-fill。
- Secondary model 设置补齐中英文案、合法模型回退与关闭时的配置清理。

## 内部与文档

- 增加 Desktop Plugin System 包格式草案和可行性审查；该系统仍为 **DRAFT**，本版本没有提供可执行 Desktop 插件能力。
- 发布前检查补齐 Rust clippy、依赖审计、机密扫描和已认证 `kimi acp` 冒烟。

## 验证

- 前端单元测试：436 项通过
- Rust 单元测试：229 项通过
- TypeScript、生产构建、Rust check、clippy、格式、i18n、差异检查和 ACP smoke 通过
