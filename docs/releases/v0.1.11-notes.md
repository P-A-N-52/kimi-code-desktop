## Kimi Code Desktop v0.1.11

相对 **v0.1.10** 的更新说明。

### Composer / 文件

- 附件改为 CLI 风格 `@路径` 文本插入（与 `@` 文件引用一致）
- 剪贴板粘贴文件：先写入 pending 上传目录，再把绝对路径插入输入框
- 附件按钮改为原生多选文件选择器，直接插入真实路径
- OS 拖放经 Tauri 窗口事件插入绝对路径（启用 `dragDropEnabled`）
- 修复连续粘贴多个文件时只保留最后一个 `@路径`
- pending 上传目录管理与删除能力（上一批提交）

### Skills / Slash 命令

- 扫描本地 skills（用户 / CLI home / 插件 / 额外目录），新会话即可用 `skill:<name>`
- ACP 已广播的命令优先，磁盘发现用于补齐与新会话菜单
- 扩充预会话 slash 目录（如 `mcp-config`、`write-goal`、`custom-theme` 等）
- 斜杠命令菜单取消「只显示前 10 条」限制，避免 skill 等条目被截断

### 设置 / 就绪

- 设置页「桌面版」显示运行中二进制版本（不仅是构建常量）
- **检查更新**：设置 → 关于可同时检测桌面版与 Kimi Code CLI 是否有新版，并打开各自 GitHub 下载页
- optional-auth：就绪检查不再强绑账号登录（上一批提交）

### 其它

- 依赖与 CI 格式修复；README 版本对齐
