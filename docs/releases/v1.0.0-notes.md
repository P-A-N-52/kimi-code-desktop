# Kimi Code Desktop v1.0.0

相对 **v0.1.13** 的更新说明。

## 原生 Goal 工作流

- Goal 不再是 Plan 式单轮循环：桌面端接入 Kimi Code 原生 Goal 状态与多轮续跑，在完成、暂停、阻塞或取消前持续同步执行状态。
- Composer 底部新增独立的一次性 Goal 开关；Manual / YOLO 会在启动前明确确认，Auto 模式直接启动。
- 支持 `/goal status`、`pause`、`resume`、`cancel`、`replace`，以及 `/goal next` 队列和可视化队列管理。
- Upcoming Goal 仅在当前 Goal 自然完成后晋升；暂停、取消或阻塞不会误启动下一项。
- Goal 完成后自动收起生命周期控件，不再残留“清除”按钮；取消操作增加二次确认。
- 修复新会话模式初始化、确认闪烁、权限模式回退、运行中替换及发送失败恢复等边界问题。

## Plan、权限与 ACP 稳定性

- 修复 Plan 模式闪烁、重复 `set_mode`、模式状态被旧快照覆盖及退出 Plan 后权限恢复问题。
- YOLO / Auto 不再替用户静默回答 Ask User，也不会误通过 Plan 审批；普通工具仍按所选权限模式处理。
- ACP 工具进度与结束状态区分更准确，避免进行中的工具提前显示完成。
- 改进 ACP 取消、异常 worker 恢复、历史重放和状态同步，减少假完成、假通知及跨会话状态污染。

## 对话、Agent 与工具界面

- Ask User 使用专用问题卡片，支持选项、自定义“其他”回答、已回答摘要和跳过状态。
- Agent / Swarm 卡片展示结构化任务信息、实时子步骤、成员状态和完成结果。
- Plan 审批显示计划正文或文件位置，普通 Bash / Edit / Read 不再误显示为 Agent 任务。
- Composer 支持内容自适应与拖动调高，整理附件、命令、文件、模型和停止/排队操作。

## 会话与窗口体验

- 会话搜索改为本地过滤，避免输入时重复请求 ACP；过期刷新结果不会覆盖新列表。
- 改进原生工作目录选择、侧栏窄屏遮罩及双栏布局。
- 系统通知只在确实仍需用户批准时出现，减少 YOLO / Auto 下的误报。
